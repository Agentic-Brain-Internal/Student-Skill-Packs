Core skills · Prompting

## What it does

Writes a tight, ready-to-paste prompt for another AI tool: ChatGPT, Gemini, Midjourney, an image or video tool, and so on. It works out which tool you're aiming at and what you actually want, asks only what it needs, and hands back one prompt.

## When to use it

- You need a prompt for a different AI tool and don't know how that tool likes to be asked.
- A prompt you use keeps giving you the wrong thing and you want it fixed.

## Try it

```
Write me a prompt for Midjourney: a photo-style image of a builders' merchant yard at sunrise for our website banner.
```

## How to get it

**Claude app (chat and Cowork)**

- Ask Claude to get it for you (see the [README](../README.md#get-the-skills)). Claude makes the file `prompt-master.zip`; upload it in **Customize > Skills > + > Create skill > Upload a skill**, then switch it on.
- Or install it as a plugin: **Customize > Plugins > Add > Add marketplace**, enter `Agentic-Brain-Internal/Student-Skill-Packs`, then install **prompt-master**.

**Claude Code**

```
claude plugin marketplace add https://github.com/Agentic-Brain-Internal/Student-Skill-Packs.git
claude plugin install prompt-master@agentic-brain-skill-pack
```

## Good to know

It only switches on when you ask it to write or fix a prompt, so it stays out of the way otherwise.
