Role packs (optional) · Operations

## What it does

Process write-ups, status reports, risk assessments, vendor reviews, change requests and capacity plans.

## When to use it

- You need to write down how a process works so someone else can run it.
- You compare suppliers or plan for a busy season.

## Try it

```
Write up our goods-in process as a step-by-step document from these notes.
```

## How to get it

**Claude app (chat and Cowork)**

- Works in Cowork and the Claude app. Open **Customize > Plugins**, find **operations** in Anthropic's plugins and install it. If it isn't listed, choose **Add > Add marketplace**, enter `anthropics/knowledge-work-plugins`, then install **operations**.

**Claude Code**

```
claude plugin marketplace add https://github.com/anthropics/knowledge-work-plugins.git
claude plugin install operations@knowledge-work-plugins
```
