## What it does

Plans and writes a series of emails: welcome emails, follow-ups after a quote, win-back emails for lapsed customers. It sets the order, timing and goal of each email, then writes them.

## When to use it

- You want a set of emails that go out over days or weeks, not a single one.
- You're setting up emails in Mailchimp, HubSpot or similar and need the words.

## Try it

```
Plan a 4-email follow-up sequence for customers who got a quote but didn't order. Then write email 1.
```

## How to get it

**Claude app (chat and Cowork)**

- Ask Claude to get it for you (see the [README](../README.md#get-the-skills)). Claude makes the file `emails.zip`; upload it in **Customize > Skills > + > Create skill > Upload a skill**, then switch it on.
- Or install it as a plugin: **Customize > Plugins > Add > Add marketplace**, enter `Agentic-Brain-Internal/Student-Skill-Packs`, then install **emails**.

**Claude Code**

```
claude plugin marketplace add https://github.com/Agentic-Brain-Internal/Student-Skill-Packs.git
claude plugin install emails@agentic-brain-skill-pack
```
