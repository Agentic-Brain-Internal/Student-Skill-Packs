By **[Anthropic](https://www.anthropic.com)**. Source: [anthropics/knowledge-work-plugins/product-management](https://github.com/anthropics/knowledge-work-plugins/tree/main/product-management). Licence: Apache-2.0.

Role packs (optional) · Product

## What it does

Feature specs, roadmap updates, stakeholder updates, competitor briefs and summaries of user research.

## When to use it

- You own a product or service and write specs or roadmaps.
- You have interview notes or survey results to turn into findings.

## Try it

```
Write a one-page spec for adding online ordering for trade customers.
```

## How to get it

**Claude app (chat and Cowork)**

- Works in Cowork and the Claude app. Open **Customize > Plugins**, find **product-management** in Anthropic's plugins and install it. If it isn't listed, choose **Add > Add marketplace**, enter `anthropics/knowledge-work-plugins`, then install **product-management**.

**Claude Code**

```
claude plugin marketplace add https://github.com/anthropics/knowledge-work-plugins.git
claude plugin install product-management@knowledge-work-plugins
```
