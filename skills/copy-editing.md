Core skills · Marketing

## What it does

Edits copy you already have instead of starting over. It goes through the text in several passes (clarity, voice, proof, specifics, flow) and tells you what it changed and why.

## When to use it

- You have a draft brochure, web page or email and want it tightened.
- Old marketing text needs a refresh but should keep its structure.

## Try it

```
Copy-edit this product page. Show me the changes as a list before you rewrite it.
```
