## What it does

Writes marketing copy for web pages: home page, landing page, pricing, product and about pages. It asks who the page is for and what they should do next, then writes headlines, sections and calls to action, with options to choose from.

## When to use it

- You're writing or rewriting a page on your website.
- You have a page that gets visits but not enquiries and want fresh copy to test.

## Try it

```

```

## How to get it

**Claude app (chat and Cowork)**

- Ask Claude to get it for you (see the [README](../README.md#get-the-skills)). Claude makes the file `copywriting.zip`; upload it in **Customize > Skills > + > Create skill > Upload a skill**, then switch it on.
- Or install it as a plugin: **Customize > Plugins > Add > Add marketplace**, enter `OWNER/claude-skill-pack`, then install **copywriting**.

**Claude Code**

```
claude plugin marketplace add https://github.com/OWNER/claude-skill-pack.git
claude plugin install copywriting@agentic-brain-skill-pack
```
