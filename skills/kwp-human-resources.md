# Human Resources (plugin)

By **[Anthropic](https://www.anthropic.com)**. Source: [anthropics/knowledge-work-plugins/human-resources](https://github.com/anthropics/knowledge-work-plugins/tree/main/human-resources). Licence: Apache-2.0.

Role packs (optional) · HR

## What it does

Job offers, interview plans, onboarding plans, performance review drafts, policy look-ups and people reports.

## When to use it

- You hire, onboard or review staff.
- People ask you policy questions you answer from the handbook.

## Try it

```
Build a first-week onboarding plan for a new warehouse supervisor.
```

## How to get it

**Claude app (chat and Cowork)**

- Works in Cowork and the Claude app. Open **Customize > Plugins**, find **human-resources** from Anthropic and install it. If it isn't listed, choose **Add > Add marketplace**, enter `anthropics/knowledge-work-plugins`, then install **human-resources**.

**Claude Code**

```
claude plugin marketplace add https://github.com/anthropics/knowledge-work-plugins.git
claude plugin install human-resources@knowledge-work-plugins
```

## Good to know

Check anything about pay, contracts or employment law with a person before you act on it.
