Core skills · Design

## What it does

Gives decks, documents and pages a consistent look. It has ten ready-made colour and font themes, shows them to you as a sample sheet, and can make a new theme to match what you describe.

## When to use it

- Your deck or report works but looks plain.
- You want several documents to look like they belong together.

## Try it

```
Show me the themes, then apply the one that suits a construction supplier to this deck.
```

## How to get it

**Claude app (chat and Cowork)**

- First look in **Customize > Skills** for it under the skills from Anthropic. If it's there, switch it on and you're done.
- Otherwise ask Claude to get it for you (see the [README](../README.md#get-the-skills)). Claude makes the file `theme-factory.zip`; upload it in **Customize > Skills > + > Create skill > Upload a skill**, then switch it on.
- Or install it as a plugin: **Customize > Plugins > Add > Add marketplace**, enter `Agentic-Brain-Internal/Student-Skill-Packs`, then install **theme-factory**.

**Claude Code**

```
claude plugin marketplace add https://github.com/Agentic-Brain-Internal/Student-Skill-Packs.git
claude plugin install theme-factory@agentic-brain-skill-pack
```

## Good to know

For your own company's look, build a brand skill instead (Lesson 7, Demo 4).

Part of the **On-brand decks** set, with PowerPoint Template Creator. Turn your company's PowerPoint template into a skill, and use Theme Factory to keep colours and fonts consistent on everything else. Switch on Skill Creator for the template step.
