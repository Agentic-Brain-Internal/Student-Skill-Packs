# Small Business (plugin)

By **[Anthropic](https://www.anthropic.com)**. Source: [anthropics/knowledge-work-plugins/small-business](https://github.com/anthropics/knowledge-work-plugins/tree/main/small-business). Licence: Apache-2.0.

Role packs (optional) · Owners and managers

## What it does

Everyday jobs for owners of small firms: chasing invoices, cash-flow snapshots, proposals, job adverts, review replies, month-end prep and a Monday briefing.

## When to use it

- You run a small business and cover several roles yourself.
- You want one plugin instead of separate sales, finance and HR ones.

## Try it

```
Give me a cash-flow snapshot from this bank export and list the invoices I should chase.
```

## How to get it

**Claude app (chat and Cowork)**

- Works in Cowork and the Claude app. Open **Customize > Plugins**, find **small-business** from Anthropic and install it. If it isn't listed, choose **Add > Add marketplace**, enter `anthropics/knowledge-work-plugins`, then install **small-business**.

**Claude Code**

```
claude plugin marketplace add https://github.com/anthropics/knowledge-work-plugins.git
claude plugin install small-business@knowledge-work-plugins
```

## Good to know

It's a large plugin with many skills. If Claude picks the wrong one, name the one you want.
