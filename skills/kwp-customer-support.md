# Customer Support (plugin)

By **[Anthropic](https://www.anthropic.com)**. Source: [anthropics/knowledge-work-plugins/customer-support](https://github.com/anthropics/knowledge-work-plugins/tree/main/customer-support). Licence: Apache-2.0.

Role packs (optional) · Customer service

## What it does

Sorts and prioritises tickets, drafts replies, writes escalation notes and turns solved problems into help articles.

## When to use it

- You answer customer emails or tickets.
- The same questions keep coming in and you want help articles for them.

## Try it

```
Draft a reply to this complaint and tell me if it should be escalated.
```

## How to get it

**Claude app (chat and Cowork)**

- Works in Cowork and the Claude app. Open **Customize > Plugins**, find **customer-support** from Anthropic and install it. If it isn't listed, choose **Add > Add marketplace**, enter `anthropics/knowledge-work-plugins`, then install **customer-support**.

**Claude Code**

```
claude plugin marketplace add https://github.com/anthropics/knowledge-work-plugins.git
claude plugin install customer-support@knowledge-work-plugins
```
