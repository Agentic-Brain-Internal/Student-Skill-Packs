## What it does

Works out your company's voice from documents you already have (past emails, proposals, call notes), writes brand guidelines from them, then checks new writing against those guidelines.

## When to use it

- Your company has no written style guide and you want one.
- Several people write customer-facing text and it all sounds different.

## Try it

```
Generate brand voice guidelines from these five proposals and our website text.
```

## How to get it

**Claude app (chat and Cowork)**

- Works in Cowork and the Claude app. Open **Customize > Plugins**, find **brand-voice** from Anthropic and install it. If it isn't listed, choose **Add > Add marketplace**, enter `anthropics/knowledge-work-plugins`, then install **brand-voice**.

**Claude Code**

```
claude plugin marketplace add https://github.com/anthropics/knowledge-work-plugins.git
claude plugin install brand-voice@knowledge-work-plugins
```
