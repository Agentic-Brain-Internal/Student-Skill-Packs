Role packs (optional) · Legal

## What it does

Contract review, NDA triage, compliance checks and meeting briefings, for in-house legal teams.

## When to use it

- You review supplier contracts or NDAs before they go to a lawyer.
- You need a quick list of the risky clauses in a document.

## Try it

```
Review this supplier contract and list the clauses we should push back on.
```

## How to get it

**Claude app (chat and Cowork)**

- Works in Cowork and the Claude app. Open **Customize > Plugins**, find **legal** from Anthropic and install it. If it isn't listed, choose **Add > Add marketplace**, enter `anthropics/knowledge-work-plugins`, then install **legal**.

**Claude Code**

```
claude plugin marketplace add https://github.com/anthropics/knowledge-work-plugins.git
claude plugin install legal@knowledge-work-plugins
```

## Good to know

It helps you prepare. It is not legal advice; a lawyer still signs off.
