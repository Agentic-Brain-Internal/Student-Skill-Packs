Already in Claude · Building skills

## What it does

Builds new skills with you, and tests and improves the ones you have. It interviews you about the task, writes the skill, and can run it with and without the skill to show the difference.

## When to use it

- You want to turn a task you do every week into a skill (Lesson 7).
- A skill you built isn't doing what you want and needs fixing.

## Try it

```
I want to build a skill. Interview me about how I write our monthly customer newsletter.
```

## How to get it

**Claude app (chat and Cowork)**

- Open **Customize > Skills**, find it among the skills from Anthropic, and switch it on.

**Claude Code**

When you ask Claude Code to get all the skills from this pack, it installs this one too. To get just this one, ask for it by name.

## Good to know

In the Claude app it's listed under Customize > Skills as a skill from Anthropic. Switch it on there.
