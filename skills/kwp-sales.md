Role packs (optional) · Sales

## What it does

Account research, call prep, call summaries with follow-up emails, pipeline and deal reviews, and outreach drafts. Gets more useful when it's connected to your CRM.

## When to use it

- You prepare for sales calls and write follow-ups.
- You review a pipeline or forecast each week.

## Try it

```
Prep me for a call with Hendricks Construction tomorrow. Here's what I know: ...
```

## How to get it

**Claude app (chat and Cowork)**

- Works in Cowork and the Claude app. Open **Customize > Plugins**, find **sales** from Anthropic and install it. If it isn't listed, choose **Add > Add marketplace**, enter `anthropics/knowledge-work-plugins`, then install **sales**.

**Claude Code**

```
claude plugin marketplace add https://github.com/anthropics/knowledge-work-plugins.git
claude plugin install sales@knowledge-work-plugins
```

## Good to know

The call-summary skill doubles as a meeting-notes skill for any call.
