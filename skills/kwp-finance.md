Role packs (optional) · Finance

## What it does

Month-end close, reconciliations, journal entries, variance analysis and financial statements, for in-house finance teams.

## When to use it

- You work in accounts or finance and do a monthly close.
- You need to explain why this month's numbers differ from budget.

## Try it

```
Explain the main variances between budget and actual in this spreadsheet.
```

## How to get it

**Claude app (chat and Cowork)**

- Works in Cowork and the Claude app. Open **Customize > Plugins**, find **finance** from Anthropic and install it. If it isn't listed, choose **Add > Add marketplace**, enter `anthropics/knowledge-work-plugins`, then install **finance**.

**Claude Code**

```
claude plugin marketplace add https://github.com/anthropics/knowledge-work-plugins.git
claude plugin install finance@knowledge-work-plugins
```

## Good to know

Built for accountants. A finance person should check its work.
