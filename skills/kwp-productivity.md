Role packs (optional) · Everyone

## What it does

Helps you plan the day, keep a task list and build up notes about your work that Claude remembers between sessions. Works best in Cowork, connected to your calendar and email.

## When to use it

- You start each day by working out what matters.
- You want Claude to keep track of people, projects and open tasks for you.

## Try it

```
/productivity:start
```

## How to get it

**Claude app (chat and Cowork)**

- Works in Cowork and the Claude app. Open **Customize > Plugins**, find **productivity** from Anthropic and install it. If it isn't listed, choose **Add > Add marketplace**, enter `anthropics/knowledge-work-plugins`, then install **productivity**.

**Claude Code**

```
claude plugin marketplace add https://github.com/anthropics/knowledge-work-plugins.git
claude plugin install productivity@knowledge-work-plugins
```

## Good to know

A plugin is a bundle of skills (and sometimes connectors). Install it from Customize > Plugins.
